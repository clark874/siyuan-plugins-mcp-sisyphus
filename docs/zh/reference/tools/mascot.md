# mascot 工具

这个工具覆盖插件吉祥物的余额与商店交互。

适用场景：你需要查看当前积累的余额，或者查看商店物品。

相关页面：

- [工具索引](./index.md)

## 动作

| 动作 | 必填字段 | 说明 |
|--------|----------|------|
| `get_balance` | 无 | 当前余额与累计收益 |
| `shop` | 无 | 商店库存、当前余额与累计收益 |
| `buy` | `item_id` | 使用余额购买 |

## 说明

- 除 mascot 本身外，其他成功工具调用会赚取一枚硬币
- 商店与余额属于吉祥物交互层

## MCP App

支持 MCP Apps 的客户端通过专用 `mascot_shop_app` 打开一次像素风自动售货机；普通 `mascot` 调用不会生成 App。刷新、余额与购买均通过模型不可见的 `mascot_shop_app_action` 执行，并在“App 软件”页独立控制。选择商品后，放大的商品图标会堆叠在取货口，用户点击取货时才真正购买并触发桌面猫猫动画；购买成功事件会归一化为 `mascot.buy`，让桌面猫猫同时显示爱心和本次取走的商品。
