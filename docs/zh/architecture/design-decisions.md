# Design Decisions

这个页面记录项目的主要架构决策。

适用场景：你在判断一个改动是否符合当前设计方向。

## 聚合工具

- 项目暴露 10 个聚合工具，而不是 100+ 个单用途工具
- 好处是 MCP 表面更小、可发现性更好、上下文成本更低

## 渐进式披露

- 常用 action 放在工具描述中
- 更细的语义放在帮助资源和参考页中

## 权限模型

- 笔记本级权限使用 `none`、`r`、`rw`、`rwd`
- 这为外部 agent 建立了可控边界

## 插件与 CLI 共用核心

- 插件 MCP server 和 CLI 共用同一套 tool registry 和 API 层
- 这样不同入口和传输方式下的行为更一致
