# 最近修改与文档差异联动设计

## 目标

将“最近更新”升级为可分页、可分组、可定位、可比较的只读工作流：左侧按年、月、日组织完整时间轴，每篇文档使用独立卡片；点击文档后同时在中间打开正文，并在右侧复用现有文档 Diff 面板比较思源文档历史检查点与当前状态。

## 默认比较基线

- 默认扫描最近 5 个候选文档历史版本。
- 优先选择第一个与当前文档块内容或可确认标题确有差异的版本。
- 若只能找到与当前正文相同的检查点，则明确显示“现有检查点正文相同”；若没有修改前检查点，则显示“历史基线不足”，不生成 `+0/-0` 统计。
- 思源文档历史通常按检查点生成，不等同于逐次按键记录；界面统一标注“最近可比较历史检查点”，并另行说明比较结论。
- `getHistoryItems.path` 指向历史归档文件，不是修改前的原始文档目录；第一阶段禁止据此推断目录移动。目录或属性类更新只能归入“检查点相同/历史不足”。
- 命名时间线节点继续承担长期、人工选择的稳定基线，两种来源在右侧面板中分别标记为“近期差异”和“时间线差异”。

## 交互

1. 最近更新列表使用 SQL 按更新时间和文档 ID 稳定分页，支持按年、月、日切换时间轴粒度。
2. 分组保留用户的展开或折叠状态；搜索时自动展开命中分组。
3. 点击文档后打开文档，并自动打开右侧 Diff 面板；空白 Diff 面板和文档树右键菜单也提供同一入口。
4. 差异块显示状态、标题路径、修改前后内容和增删行统计。
5. 点击差异块时滚动中间文档到对应当前块；删除块使用最近仍存在的相邻块定位。
6. 左侧卡片进入视口后惰性计算并缓存结果；仅正文变化显示变更块数及增删行数，其余更新采用明确分类。

## 架构

- 新增共享的最近历史比较服务，同时供插件前端与 `timeline` 聚合工具使用。
- 共享服务只通过思源 HTTP API 读取当前块 DOM 和文档历史，不访问工作区文件系统。
- 现有 `block-diff` 继续作为唯一块解析、匹配和行统计实现，并扩展章节路径推导。
- `VersionDiffPanel` 接受“命名时间线”或“最近历史”两类选择；最近历史模式隐藏全部回滚入口。
- 新增只读动作 `timeline(action="compare_recent", documentId, page, pageSize)`，执行既有笔记本读取权限检查并返回分页差异。

## 安全边界

- `compare_recent` 不创建仓库快照、不写属性、不回滚文档。
- 历史路径只在服务内部用于读取，不向 MCP 返回。
- 最近历史模式不显示整篇或块级回滚按钮。
- 现有命名时间线的高风险回滚权限与确认机制保持不变。

## 验证

- 单元测试覆盖日期分组、精确文档历史选择、同内容跳过、无历史、分页、章节路径和权限拒绝。
- 全量测试、类型检查和生产构建。
- 部署到当前思源实例后验证分组、打开文档、右侧差异、滚动定位和真实 MCP 调用。
