## 分层结果与边界

- 唯一 name、唯一 alias、句中 alias、歧义四类 Hit@1/Hit@5 均为 100%；唯一 name、唯一 alias 和歧义题完全在本地完成。
- 纯语义题 Hit@1 为 60%、Hit@5 为 80%，说明命名空间没有取代语义发现，但真实知识库仍存在召回缺口。
- 跨语言题 Hit@1/Hit@5 均为 40%。这是受控命名空间中的自然语言英文 alias 覆盖不足，不应通过字符模糊匹配或第二套索引掩盖。
- 两道无答案负例在原生语义、旧知识编排与新编排中均发生误命中，误命中率为 100%。当前思源语义接口没有可供 MCP 校准的稳定拒答阈值，因此结果必须继续作为候选而非证据；本版不虚构自动拒答能力。
- 命名空间解析正确率为 90%；未通过的两题正是无答案负例，而不是唯一锚点或歧义题被错误解析。

## 语义索引生命周期

另用一次性临时文档完成新增、更新、删除实机测试：

1. 新建随机唯一文本后，原生语义检索返回其段落块；
2. 更新为另一随机唯一文本后，第一次查询即命中同一稳定块；
3. 删除临时文档后，`blocks` 与 `block_embeddings` 对应记录第一次复核即均为 0；
4. 临时文档已清理。

因此当前思源 3.8.1 原生 `block_embeddings` 能随 MCP 写入维护增量生命周期；没有引入 QMD 双索引的必要。

## 发布判断

本版达到“受控命名空间优先、歧义保守、语义兜底、零第二索引”的目标。后续优化应优先补高价值跨语言 alias、扩大真实查询评测集，并在思源提供可靠分数或阈值后再研究拒答校准；不以 QMD、Fuse.js、ranx 或本地模型作为默认路线。
